# 🌍 AI Civilization Simulator - Project Overview

## What We Built

A **completely autonomous AI civilization simulator** where Claude-powered agents build a society from scratch through natural interactions. This isn't scripted behavior - agents make their own decisions based on personality, goals, memories, and current situations.

---

5. **Unpredictable**: Every simulation is unique - agents do unexpected things

## 🏗️ Architecture

### Backend (Python + FastAPI)

```
backend/
├── agent.py              # Agent class with personality, goals, memory
├── world_state.py        # World environment (50x50 grid, biomes, resources)
├── orchestrator.py       # Agent lifecycle & Claude API integration
├── memory_system.py      # ChromaDB semantic memory (episodic/semantic/procedural)
├── communication.py      # Natural language dialogue generation
├── knowledge_system.py   # Teaching and knowledge transfer
├── crafting.py           # Recipe-based item creation
├── server.py             # FastAPI REST + WebSocket endpoints
└── main.py               # Simulation runner
```

**Key Technologies**:
- **Claude API**: Agent decision-making (claude-3-5-sonnet)
- **ChromaDB**: Vector embeddings for semantic memory
- **FastAPI**: REST API + WebSocket for real-time updates
- **SQLite**: World state persistence
- **Asyncio**: Concurrent agent actions

### Frontend (React + TypeScript + Vite)

```
frontend/src/
├── types/
│   └── index.ts          # TypeScript interfaces
├── hooks/
│   └── useApi.ts         # Data fetching hooks
├── components/
│   ├── AgentCard.tsx     # Agent status card
│   ├── AgentDetails.tsx  # Detailed agent view
│   └── WorldMapComponent.tsx  # Visual world map
├── App.tsx               # Main application
└── main.tsx              # Entry point
```

**Key Technologies**:
- **React 18**: UI components
- **TypeScript**: Type safety
- **Vite**: Fast dev server
- **Axios**: API client

## 🧠 Core Features

### 1. Autonomous Agents
Each agent has:
- **Personality** (Big Five: openness, conscientiousness, extraversion, agreeableness, neuroticism)
- **Goals** with priorities
- **Skills** that improve with practice
- **Inventory** for gathered resources
- **Current action** (move, gather, craft, communicate, rest, build, teach, trade)

Agents use Claude API with system prompts defining their personality and context to make autonomous decisions.

### 2. Memory System (ChromaDB)
- **Episodic**: Events and experiences ("Yesterday I met Alice near the river")
- **Semantic**: Facts about world ("Bob is a skilled hunter but untrustworthy")
- **Procedural**: Learned skills ("How to craft a stone axe")

Agents can search memories semantically and learn from past experiences.

### 3. Communication & Dialogue
- Natural language conversations between agents
- Generated by Claude based on personality and context
- Builds relationships (trust, friendship)
- Share information and collaborate

### 4. Knowledge Transfer
- Agents can teach skills to each other
- Success depends on teacher skill level
- Students improve through learning
- Knowledge spreads through civilization

### 5. Crafting System
- Recipes for tools, shelters, food
- Requires resources and skills
- Quality depends on crafting skill
- Practice improves skills

### 6. World Environment
- **50x50 grid** with biomes (forest, plains, mountain, river, desert, village)
- **Resources** that regenerate daily
- **Locations** agents can explore
- **Day/night cycle** and weather
- **Events** logged to history

## 🎮 How to Run

### Quick Start
```bash
./start.sh
```

This will:
1. Set up Python virtual environment
2. Install backend dependencies
3. Start FastAPI server (port 8000)
4. Start simulation engine
5. Install frontend dependencies
6. Start React dev server (port 3000)

### Manual Start

**Backend**:
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Edit .env with your ANTHROPIC_API_KEY
python main.py
```

**Frontend**:
```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000 to watch civilization emerge!

## 📡 API Endpoints

### REST API (localhost:8000)
- `GET /world` - World state (tick, day, time, weather)
- `GET /world/map` - Full world map with locations
- `GET /agents` - All agents and their status
- `GET /agents/{id}` - Specific agent details
- `GET /agents/{id}/memories` - Agent's memory history
- `GET /agents/{id}/relationships` - Agent relationships
- `POST /agents/{id}/goals` - Add new goal to agent
- `GET /events` - Recent world events
- `POST /world/intervene` - Trigger custom world event

### WebSocket
- `WS /ws` - Real-time world updates (1 second interval)

## 🌟 What Makes It Interesting

### Emergent Behavior Examples
Watch for:
1. **Social Networks**: Agents form relationships based on interactions
2. **Knowledge Spread**: Skills propagate through teaching
3. **Trade Routes**: Agents gather different resources and trade
4. **Specialization**: Some become hunters, others crafters
5. **Exploration**: Agents discover new areas and share knowledge
6. **Cultural Artifacts**: Shared beliefs emerge from conversations

### No Scripting
Everything is emergent:
- Agents weren't programmed to form friendships - they do it because their personality (high agreeableness) leads them to
- Agents weren't told to teach - they do it because they have knowledge and meet others who don't
- Agents weren't scripted to explore - their curiosity (high openness) drives them to

### Every Run is Unique
With 5 agents making autonomous decisions, the exact same code produces different civilizations each time:
- Different relationships form
- Different knowledge spreads
- Different social structures emerge
- Different events happen
