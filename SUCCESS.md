Agents use Claude API to make their own decisions based on:
- Personality traits (Big Five model)
- Current goals and priorities
- Memories of past experiences
- Current situation and needs

**No scripts** - agents think for themselves!

### 2. **Emergent Behavior** 🌊
Watch civilization emerge from simple rules:
- Relationships form naturally from interactions
- Knowledge spreads through teaching
- Social structures develop organically
- Agents specialize based on personality

**Unpredictable** - every simulation is unique!

### 3. **Sophisticated Systems** 🧠

**Memory System (ChromaDB)**:
- Episodic: Events and experiences
- Semantic: Facts about the world
- Procedural: Learned skills

**Communication**:
- Natural language dialogue between agents
- Generated by Claude based on personality
- Builds trust and friendship over time

**Knowledge Transfer**:
- Agents can teach each other skills
- Success depends on teacher's mastery
- Students improve through learning

**Crafting**:
- Recipes for tools, shelters, food
- Quality depends on skill level
- Practice improves abilities

### 4. **Real-Time Visualization** 👁️
- **World Map**: 50x50 grid showing biomes, resources, agents
- **Agent Cards**: Status, inventory, current action
- **Agent Details**: Personality, goals, skills, memories
- **Event Log**: Civilization history in real-time

### 5. **Complete Full-Stack System** 🏗️

**Backend (Python)**:
- FastAPI REST + WebSocket server
- Claude API integration for decision-making

**Frontend (React + TypeScript)**:
- Real-time world visualization

- Beautiful UI with animations

## 🚀 How to Run

### Super Easy Start
```bash
./start.sh
```

This single command:
1. Sets up Python virtual environment
2. Installs all dependencies
3. Starts FastAPI server (port 8000)
4. Launches simulation engine
5. Starts React frontend (port 3000)

Then open http://localhost:3000 and watch civilization emerge!

### What You'll See
- 🗺️ **Map View**: 50x50 world with colored biomes, agent markers moving in real-time
- 🤖 **Agent Panel**: 5 agents (Alice, Bob, Charlie, Diana, Eve) with status cards
- 📊 **Details Panel**: Click any agent to see personality, goals, memories, skills
- 📜 **Event Log**: Live feed of actions, conversations, discoveries

---

## 🌟 Cool Things You'll Observe

### Emergent Social Behavior
- Agents with high **extraversion** naturally seek out others
- Agents with high **agreeableness** build friendships faster
- Agents with high **openness** explore more and discover new areas
- Knowledge spreads through the population as agents teach each other

### Unscripted Events
Example sequence:
1. Alice (high openness) explores and finds a forest
2. She gathers wood and improves her gathering skill
3. Bob (high extraversion) approaches Alice
4. They have a conversation, Alice teaches Bob about gathering
5. Bob's skill improves, he starts gathering too
6. Both build trust and friendship through interaction
7. They decide to collaborate on building a shelter

**None of this was scripted** - it emerged from their personalities and situation!
