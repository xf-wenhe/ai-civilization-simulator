# Multi-Agent AI Civilization Simulator

An autonomous world where AI agents build a civilization from scratch through natural interactions.

## Quick Start

```bash
# Backend (Python)
cd backend
pip install -r requirements.txt
python main.py

# Frontend (React)
cd frontend
npm install
npm run dev
```
