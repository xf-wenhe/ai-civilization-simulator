# 🌍 AI文明模拟器 - 项目介绍

## 这个项目是做什么的？

这是一个**完全自主的AI文明模拟器**，让5个由Claude驱动的AI智能体从零开始建立文明！

---

## 🎯 核心特点

### 1. **真正的自主性** 🤖
- 每个AI智能体都有独特的**性格特征**（开放性、尽责性、外向性、宜人性、神经质）
- 他们自己决定要做什么：探索、采集资源、与其他智能体交流、学习技能、建造物品
- **没有脚本！** 所有决策都是AI基于性格、目标和记忆自主做出的

### 2. **记忆系统** 🧠
- **情景记忆**：记录发生过的事件（"昨天我在河边遇到了Alice"）
- **语义记忆**：学到的知识（"Bob是个熟练的采集者"）
- **程序记忆**：学会的技能（"如何制作石斧"）

智能体会记住经历，并从中学习！

### 3. **社交互动** 💬
- 智能体之间会用**自然语言对话**（由Claude生成）
- 建立**人际关系**：信任、友谊、互动次数
- **分享知识**：互相教学，技能传播

### 4. **技能系统** ⚡
- 采集、制作、社交等技能会随着练习提升
- 智能体可以**互相教学**，知识在人群中传播
- 技能水平影响成功率

### 5. **世界环境** 🗺️
- **50×50的地图**，包含森林、平原、山脉、河流、沙漠等生物群落
- **资源系统**：食物、木材、石头、水等资源
- **日夜循环**和天气系统

---

## 🔥 为什么这个项目很有趣？

### **涌现行为**（Emergent Behavior）
最神奇的是：**没有写任何脚本告诉AI要做什么，但文明会自然涌现！**

举个例子：
1. **Alice**（高开放性）喜欢探索，发现了森林
2. 她采集木材，提高了采集技能
3. **Bob**（高外向性）主动接近Alice
4. 两人对话，Alice教会Bob采集技巧
5. Bob的技能提升，也开始采集
6. 两人建立了信任和友谊
7. 他们决定合作建造庇护所

**这一切都不是编好的程序，而是AI基于性格和情境自主做出的决定！**

## 🚀 技术架构

### 后端（Python）
- **agent.py** - 智能体类（性格、目标、记忆）
- **world_state.py** - 世界环境（地图、资源、位置）
- **orchestrator.py** - 智能体生命周期 + Claude API集成
- **memory_system.py** - ChromaDB语义记忆系统
- **communication.py** - 自然语言对话生成
- **knowledge_system.py** - 知识传授机制
- **crafting.py** - 物品制作系统
- **server.py** - FastAPI服务器（REST + WebSocket）

### 前端（React + TypeScript）
- **AgentCard** - 智能体状态卡片
- **WorldMapComponent** - 可视化世界地图
- **AgentDetails** - 详细信息面板
- **useApi** - API数据获取钩子

### 关键技术
- **Claude API**: 智能体决策（claude-3-5-sonnet）
- **ChromaDB**: 向量嵌入语义记忆
- **FastAPI**: REST API + WebSocket实时更新
- **SQLite**: 世界状态持久化
- **Asyncio**: 并发智能体行动
